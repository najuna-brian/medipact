# Archived Migration Scripts

This folder contains one-time migration scripts that were used during development but are no longer needed for regular operations.

## Contents

- `migrate-fhir-*.js` - FHIR schema migration scripts
- `migrate-hedera-columns.js` - Hedera account column migrations
- `migrate-pricing-fields.js` - Pricing field migrations
- `run-migration.sh` - Migration runner script
- `manual-test-data.sql` - Manual test data SQL

## Note

These scripts are kept for historical reference. Do not run them on production databases.
