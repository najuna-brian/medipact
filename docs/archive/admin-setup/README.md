# Archived Admin Setup Scripts

This folder contains one-time admin setup and maintenance scripts.

## Contents

- `create-admin-*.sql` - SQL scripts for creating admin users
- `create-admin-via-api.js` - API-based admin creation
- `setup-admin.js` - Admin setup utility
- `reset-admin-password.sql` - Password reset script
- `cleanup-*.js` - Data cleanup utilities
- `regenerate-demo-credentials-md.js` - Demo credentials generator

## Note

These scripts are kept for reference. Use `npm run setup-admin` in backend for admin setup.
